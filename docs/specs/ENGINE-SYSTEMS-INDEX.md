# Shader Forge Systems Index

Date: 2026-08-31

`engine_sessiond` remains a loopback-only control plane: it refuses non-loopback bind hosts such as `0.0.0.0` and `::`, keeps session `rootPath` immutable after creation, bounds public JSON bodies while bytes arrive, and owns the revision-safe text-file operation journal. That journal records canonical workspace identity (path plus filesystem `dev`/`ino`), validates the full event sequence and coherent applying/undoing effect shapes on load, appends failure/recovery transitions, and finalizes code-trust artifacts before an operation is `applied` or `undone`. It persists the latest strict bounded validation summary plus up to eight actor-attributed `validated` events for previewed/approved spatial operations. The lease-free HTTP validator now stages the full animation/content/foundation snapshot, verifies private proposed bytes, native-validates and evaluates rest plus at most 64 exact phase/time samples, rejects live-manifest drift, and compare-and-swap records only controlled counts/failures. Restart rejects malformed or mismatched validation provenance; public views never expose private bytes or raw native diagnostics. One semantic dispatcher sends scene and spatial apply/undo through their respective native mutation validators inside the serialized SessionStore lane, with spatial validation directly rechecking current truth and the covering lease without recursively taking the mutation lock. Native spatial child processes have a fixed timeout. All supported mutations, including CLI provenance promote/quarantine and `sf-mcp` spatial attachment changes, share this authority; artifact files use atomic replacement. Cooperative engine clients are covered; hostile out-of-process filesystem swaps at the OS syscall boundary are not an adversarial security guarantee. Non-spatial MCP mutation stays disabled until each operation family persists resource keys and enforces equivalent leases.

Scene/data/runtime now share a strict optional prefab `[component.camera]` perspective source of truth. One root `player_camera` wins over `player_spawn`; its composed transform and authored float32-compatible FOV/clip values drive runtime debug projection, while ordinary scenes retain a 70/0.15/1000 fallback. Parented player cameras fail validation until true parent/local TRS composition exists, and stale quickloads cannot replace the current preferred authority. The native spatial tool renders deterministic close-camera samples plus an optional strict authored root `player_camera` view; sessiond binds those frames to exact revisions and leases in atomic immutable review packets.

Spatial authoring now has a native schema/query/cook slice, compatible v1 plus strict v2 attachment profiles, strict optional schema-v2 cone-twist limits and diagnostic capsules, a strict optional prefab-only box-collision component in `DataFoundation`, deterministic schema-v2 clip pose sampling, sampled v2 two-bone secondary-hand IK, exact prefab-bound authored visual-box evidence, and deterministic depth-tested close/player-camera sample rendering. Limits/capsules are generation-safe bone snapshot data and cook as deterministic object-or-null fields; prefab collision is typed source snapshot truth independent of render procgeo. Native rest/sample evaluation reports rest-relative cone swing and signed twist plus diagnose-only capsule-axis-to-authored-collision-OBB surface clearance without mutating or clamping the pose. `shader_forge_spatial` emits exact typed aggregate/per-bone joint-limit and aggregate/per-capsule clipping objects; its `capture-sample` command turns the sampled pose and authored procgeo box into four bounded close-camera clean RGB PNGs plus an optional strict authored root `player_camera` frame, with explicit source identity and no debug proxy cards. Sessiond and Assets validate evaluator order, geometry, derived metrics, and aggregate truth fail closed. Missing collision or capsule inputs remain exact typed unavailable evidence rather than silently passing, and tangency is clear with zero violation. Sessiond stages exact animation files, all authored `content/**/*.toml`, and the data-foundation manifest, exposes their sorted revision manifest, and fails closed on source drift or symbolic paths. Validated operations can reserve a new review ID and recapture selected authored phase sets under exact source-read, capture-write, and review-write leases; sessiond validates frame metadata/dimensions, performs a final manifest/lease recheck, atomically publishes an immutable packet, serves its manifest/referenced PNGs, and releases all capture leases. CLI and `sf-mcp` expose thin validation plus explicit review reserve/recapture/read adapters, and MCP exposes the immutable typed review resource; `spatial_attachment_read` returns exact revision-bound rest or authored sampled evidence without acquiring leases or creating operations. Assets validates/publishes a selected authored phase or loads a shared review ID, rejects malformed/mismatched packets, and displays only packet-referenced PNGs in a separate immutable-evidence panel; its diagnostic schematics remain non-review evidence. Schema-v1 two-hand sampled output remains explicitly pre-IK; v2 exposes physical reach plus separate contact/angular tolerance truth. Runtime collision/physics consumption and generic bake/runtime consumption remain deferred; see [ENGINE-SPATIAL-AUTHORING-SPEC.md](/mnt/s/Development/AI-Game-Engine/docs/specs/ENGINE-SPATIAL-AUTHORING-SPEC.md).

The shell now consumes the durable operation journal through a global `Activity` bottom-dock tab. `App` owns one sessiond SSE subscription for both Activity and Assets operation notifications. Activity reloads active-workspace list/detail state, while Assets receives an event epoch and authoritatively refetches its active operation with selection/operation race guards. Approval updates actions. Conflict rereads authored bytes, preserves visibly stale candidate evidence, and retains its captured lease only after successful parse and refreshed resource coverage. Reject/apply/undo clear and reread the appropriate evidence and clean up only the connection captured by that event/action, never a newer one; Undo reacquires explicitly after apply. Activity itself shows public provenance and exact bounded text diffs and supports lease-free approve/reject; it deliberately cannot apply/undo, coordinate, or expose internal before/proposed bytes. Public validation summaries now exist in the operation contract, but Activity rendering for them remains deferred.

The shell-native `Code` workspace now owns bounded file browsing, revision-bound Monaco source/diff tabs, current-file search beside `Inspect`, dirty-draft retention, typed revision/state/code-trust conflicts, and explicit Preview/Approve/Reject/Apply/Undo over the same durable operation journal. It never writes through `/api/files/write`; reviewed candidates are bound to exact draft bytes. Request-generation plus session/tab/path/operation guards reject late reads, event refreshes, and actions, while apply/undo baseline refresh uses an expected-draft comparison so a newer edit survives. Active project-session changes keep foreign dirty tabs detached and read-only until their original session returns. Authoritative 409 operation state is adopted only when id, session, and path match. The preserved `web/` editor is an optional compatibility bridge rather than the default workflow.

The React shell now uses one strict v1 browser-persisted layout record: active workspace; per-workspace left/right visibility, tab, and preferred width; and one shared bottom-dock tab, collapsed state, and preferred height. Header toggles, bounded pointer/keyboard separators, and `Reset` operate that record. Layout persistence contains chrome only and falls back to defaults on malformed/unavailable storage. `Playtest` starts with side panes hidden; at narrow width the right pane stays reachable as an overlay drawer instead of consuming the center workspace. `Code` and `World` remain mounted across ordinary workspace navigation. `World` uses draft-preserving `Edit`/`Verify`, explicitly detaches dirty drafts across incompatible project/session changes, and sends all scene/prefab saves through the revision-bound semantic operation lane before Play requests Build + Run. Queued, conflicting, late, or uncertain results preserve drafts; successful apply is reconciled by authoritative operation/file identity. World load, reload, save, create, and duplicate responses also retain request generation plus workspace/path authority, preventing an A-to-B-to-A switch from reviving stale state. Runtime/build request generations reject HTTP completions after newer commands or SSE truth, stopped builds cancel pending auto-run, and runtime telemetry no longer changes the authored World selection. Explorer, Git, package, profiling, trust-summary, and trust-approval reads likewise require independent request generations plus active-session identity. Package, capture, trust, and Activity review actions retain the initiating workspace-selection generation; workspace changes synchronously invalidate those lanes, their transient busy state, and pending build auto-run intent. Workspace-list and host-directory-picker reads also use request generations, picker close invalidates pending navigation, and workspace CRUD locks selection/edit/delete until completion. Terminal tabs use valid sibling tab/close controls with keyboard navigation and named shell/status/panel semantics; World mode and workspace actions expose explicit accessible state/names, and the collapsed bottom dock shows only Restore. `Playtest` defaults to one plain status/action surface with raw settings, state, logs, and activity under collapsed `Diagnostics`; the top chrome no longer duplicates runtime controls.

The Unity migration lane now parses text-YAML `GameObject` plus `Transform`/`RectTransform` documents into parent-linked Shader Forge scene entities and scene-owned prefabs, preserving source file IDs and local transforms with deterministic quaternion-to-Euler output. Valid perspective `Camera` optics reuse the strict prefab camera component and retain their source component ID. The Godot lane parses text `.tscn` node headers and explicit `Vector3` position/rotation/scale fields into parent-linked entities and node-type-tagged prefabs, retaining source paths/types in generated comments. Manifests and reports expose `mapped_scene_entities`, and normalized source-name collisions receive deterministic names. Unity prefab instances/non-camera components/orthographic and enabled-state camera semantics/assets/coordinate-system remediation and Godot matrices/resource instances/components/assets remain manual; binary Godot `.scn` files stay reviewable placeholders without counting as mapped content.

The game-facing AI provider core now supports deterministic fake, optional local Ollama, and a disabled-by-default OpenRouter/Kimi K3 BYOK lane through the same CLI/sessiond request path. Real requests carry a manifest-backed output-token ceiling (default 256) and return normalized provider token usage when present; OpenRouter validates 1–4096, pins `https://openrouter.ai/api/v1/` and `OPENROUTER_API_KEY`, rejects arbitrary remote endpoint/key redirection, bounds responses to 1 MiB, and excludes credentials from public results. Other hosted provider types remain inspection-only. External development agents such as Codex, Grok, and Google Antigravity stay outside this runtime provider core and connect through `sf-mcp`.
